### 🚀 机场推荐与选购指南

在选择机场服务时，建议优先考察以下指标：
- **节点覆盖**：提供香港、日本、新加坡、美国等多地优质 BGP / IEPL 专线。
- **协议支持**：支持 Vless, Trojan, Shadowsocks, Hysteria2 等最新现代化协议。
- **设备兼容**：完美兼容 Windows / macOS / iOS (Shadowrocket) / Android 客户端。

---

### 📱 Shadowrocket (小火箭) 快速配置步骤

1. 打开 iOS 端 Shadowrocket (小火箭) 客户端。
2. 点击右上角 `+` 号添加节点，类型选择 **Subscribe**。
3. 在 URL 栏中粘贴您的机场订阅链接，点击保存。
4. 勾选订阅更新并开启首页开关即可完成连接。

---

### 💻 Clash 客户端快速配置步骤

1. 下载并安装 Clash Verge 或 Clash for Windows 客户端。
2. 打开客户端，前往 **Profiles (配置)** 页面。
3. 粘贴您的机场一键订阅链接，点击 **Import** 下载节点信息。
4. 在 **Proxies (代理)** 页面选择节点，开启 **System Proxy (系统代理)** 即可使用。
