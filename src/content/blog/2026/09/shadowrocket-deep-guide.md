## ⚡ 三步极速上手 Shadowrocket (小火箭)

无需复杂设置，跟着以下三个核心步骤，即可快速在 iPhone / iPad 上开启小火箭代理：

1. **获取外区 Apple ID 并在 App Store 下载 Shadowrocket**  
   使用美区或港区 Apple ID 登录 App Store（切记仅在 App Store 登录，不要在 iPhone 设置中的 iCloud 登录），搜索并购买下载正版小火箭应用。
2. **在小火箭中一键导入您的机场订阅链接**

3. **选择「配置」模式并开启代理开关**  
   在首页底部将路由模式设为 **`配置 (Config)` 模式**（智能分流国内直连、国外走代理），点击顶部开关开启连接，首次提示“添加 VPN 配置”时输入手机解锁密码授权即可。

## 💡 第一章：Shadowrocket 架构解析与 iOS 代理机制

### 1.1 iOS VpnService 与 NetworkExtension 架构
iOS 系统对后台进程和网络接管有着极其严苛的沙盒限制。Shadowrocket 利用了 Apple 官方的 **NetworkExtension 框架 (NEPacketTunnelProvider)**。当您在小火箭中开启连接时，系统会在 iOS 内核层创建一个虚拟网卡接口。

所有由应用程序（如 Safari、YouTube、Twitter、微信）发起的 TCP/UDP IP 数据包，都会被重定向至小火箭的本地代理引擎。引擎在毫秒级时间内比对分流规则后，决定直接由本地发包（直连）或通过加密代理通道转发。

```

              │    Shadowrocket 智能网络策略中心         │
              └────────────────────┬────────────────────┘
                                   │
      ┌────────────────────────────┼────────────────────────────┐
      │                            │                            │
┌─────┴───────────────┐  ┌─────────┴─────────────┐  ┌────────────┴──────────┐
│  多协议兼容引擎     │  │   智能规则分流系统     │  │  场景与快捷指令联动    │
│ (Shadowsocks/VMess/ │  │ (域名/IP/GEOIP/按需)  │  │ (Wi-Fi/蜂窝自动切换)   │
│ Trojan/Hysteria2)   │  │                        │  │                        │
└─────────────────────┘  └────────────────────────┘  └────────────────────────┘
```

### 1.2 为什么小火箭在 iOS 生态中首屈一指？
- **极致省电**：高度优化底层代码，后台悬挂 24 小时仅消耗微乎其微的电量，不发热、不卡顿。
- **协议全覆盖**：支持最新传输协议，包括 Shadowsocks (SS / SS-2022)、VMess / VLESS、Trojan、Hysteria2 (Hy2)、TUIC v5 及 Snell。
- **全自动化控制**：支持按 Wi-Fi 网络 SSID 名称自动开关、iOS 桌面 Widget 小组件、Siri 快捷指令联动。

## 📲 第二章：美区/外区 Apple ID 获取与小火箭正版下载全流程

### 2.1 为什么中国大陆 App Store 搜索不到小火箭？
因中国大陆区 App Store 下架了所有网络代理类应用，因此在国区 App Store 中搜索“Shadowrocket”只会出现大量模仿或虚假的模仿软件。您必须使用外区（如美国、香港、日本、台湾等）的 Apple ID 才能下载正版小火箭。

### 2.2 获取外区 Apple ID 的安全方式
1. **自己注册外区 Apple ID**：访问 Apple 官方网站 `appleid.apple.com`，注册新的 Apple 账号，国家地区选择“美国”，付款方式选择“无”，填入合规的美区账单地址即可。
2. **购买或使用正版独享 ID**：前往 [小火箭官方下载与账号获取中心](https://shadowrrocket.com.cn/download.html) 获取正版账号。

> [!CAUTION]
> **绝对不要在 iPhone 的「设置 → iCloud」中登录他人或公共账号！**  
> 仅在 **App Store 应用内部** 登录外区 ID。若在 iCloud 中登录非本人账号，设备极易被恶意远程锁死为“丢失模式”导致关卡断联。

### 2.3 App Store 登录与下载步骤
1. 打开 iPhone 上的 **App Store** 应用。
2. 点击右上角个人头像图标，滑动到最底部，点击 **“退出登录 (Sign Out)”**。
3. 在顶部输入您获取的外区 Apple ID 与密码，点击 **“登录 (Sign In)”**。
4. 搜索框输入 `Shadowrocket`，认准开发者为 `Shadowrocket` 官方应用（售价约 $2.99 美元），点击下载安装。
5. 下载完成后，建议立即退出外区 ID，换回您个人的国区 Apple ID，不影响小火箭的后续正常使用。

## 📦 第三章：节点订阅导入与自动化管理

```
复制订阅 URL ──> 打开小火箭右上角 [+] ──> 类型选择 [Subscribe] ──> 粘贴链接保存 ──> 开启 [配置] 模式
```

### 3.1 一键粘贴 URL 导入
1. 登录您向代理服务商（机场）购买账号后获取的专属小火箭订阅 URL（通常以 `https://` 开头）。
2. 打开 Shadowrocket，点击主界面右上角的 **`+` 号**。
3. 在弹出的添加节点页面中，点击 **“类型 (Type)”**，将其切换为 **`Subscribe` (订阅)**。
4. 在 **“URL”** 栏中长按粘贴刚才复制的订阅链接。
5. 在 **“备注 (Remark)”** 栏填入机场名称（如“专线机场”）。
6. 点击右上角的 **“保存 (Save)”**。小火箭会自动联网拉取并解析所有代理节点。

### 3.2 扫码与剪贴板自动唤醒
- **二维码扫码**：点击小火箭首页左上角的 **扫码图标**，扫描机场网页上的小火箭专属二维码，即可自动完成节点导入。
- **剪贴板自动识别**：复制订阅 URL 后打开小火箭，应用会自动弹窗识别剪贴板内容，询问是否自动填充导入。

### 3.3 自动更新与后台静默刷新设置
为了防止节点 IP 发生变动或服务商升级时导致无法连通，建议进行如下配置：
- 进入 **「设置 (Settings)」 → 「订阅 (Subscribe)」**。
- 开启 **“打开时更新 (Update on Open)”**：每次启动小火箭自动获取最新节点。
- 开启 **“自动更新 (Auto Update)”**：配置自动刷新周期（建议设定为 1440 分钟/24小时），实现全自动后台静默维护。

## 🔀 第四章：高级路由模式与 Rule 规则分流深度特训

在 Shadowrocket 首页底部找到 **全局路由 (Global Routing)**，可灵活切换以下四种核心工作模式：

| 路由模式 | 英文标识 | 推荐指数 | 工作逻辑与最佳场景 |
| :--- | :--- | :---: | :--- |
| **配置模式 (强烈推荐)** | `Config` | 🌟🌟🌟🌟🌟 | **日常最佳选择**。智能识别流量：国内网站直连毫秒响应、国外网站走代理 |
| **代理模式** | `Proxy` | 🌟🌟 | **全量强制代理**。所有流量一律通过当前选定的单一节点转发，适合特殊测试 |
| **直连模式** | `Direct` | 🌟🌟 | **完全直连**。绕过所有代理节点，所有网络请求直接出网，适合临时关停代理 |
| **场景模式** | `Scene` | 🌟🌟🌟🌟 | **自动感应**。根据 Wi-Fi SSID 名称或蜂窝移动网络自动应用预设的场景规则 |

### 4.1 核心分流规则语法与类型
Shadowrocket 规则库支持高度精准的匹配语法：
- `DOMAIN-SUFFIX,google.com,Proxy`：所有以 `google.com` 结尾的域名走代理。
- `DOMAIN-KEYWORD,telegram,Proxy`：包含 `telegram` 关键词的域名走代理。
- `IP-CIDR,192.168.0.0/16,DIRECT`：局域网段 IP 直接连接。
- `GEOIP,CN,DIRECT`：中国大陆地区的 IP 地址全部直连。
- `FINAL,Proxy`：兜底规则，未匹配到前面任何规则的流量走默认代理。

### 4.2 导入社区第三方开源高精细规则集
您还可以导入社区著名的开源规则文件（如 Loyalsoldier 规则）：
1. 在小火箭底部点击 **「配置 (Config)」** 标签页。
2. 点击右上角的 **`+`** 号。
3. 粘贴远程规则配置链接（如 `https://raw.githubusercontent.com/Loyalsoldier/clash-rules/release/shadowrocket.conf`）。
4. 点击下载好的配置文件，选择 **“使用配置 (Use Configuration)”** 即可。

## 🛡️ 第五章：DNS 防污染、HTTPS 证书解密与广告 Rewrite 重写

### 5.1 DoH / DoT 加密 DNS 设置
传统 DNS 查询采用明文 UDP 53 端口，容易遭遇运营商 DNS 劫持与域名污染。小火箭支持设置加密 DNS：
进入 **「设置」 → 「DNS」**，添加加密 DNS 上游：
- `https://doh.pub/dns-query` (腾讯 DNSPod DoH)
- `https://dns.alidns.com/dns-query` (阿里 AliDNS DoH)
- `https://1.1.1.1/dns-query` (Cloudflare DoH)

### 5.2 CA 根证书安装与 HTTPS 网页广告重写 (Rewrite)
通过在小火箭中生成并信任本地 CA 证书，小火箭可以实现 HTTPS 流量解密与网页去广告功能：
1. 进入 **「配置」 → 点击当前使用的配置文件 → 「HTTPS 解密」**。
2. 开启 HTTPS 解密开关，点击 **“生成新的 CA 证书”**。
3. 点击 **“安装证书”**，系统会自动跳转至 Safari 下载描述文件。
4. 前往 iPhone **「设置 → 已下载描述文件」** 点击安装。
5. 前往 iPhone **「设置 → 通用 → 关于本机 → 证书信任设置」**，找到 Shadowrocket 证书，开启 **全信任开关**。

## ⚡ 第六章：节点延迟测速、自动选优组与按需连接 (On-Demand)

### 6.1 延迟测速机制 (ICMP vs TCP vs HTTP)
在首页点击 **“连通性测试 (Connectivity Test)”**：
- **TCP 握手测速**：测量手机到节点代理服务器的 TCP 连接建立时间，反映服务器基础网络质量。
- **HTTP 端到端测速**：测量实际通过代理成功加载 `http://www.gstatic.com/generate_204` 的响应时间，最能贴切反映用户真实看视频、刷网页的体验。

### 6.2 Auto-Select 自动最低延迟节点绑定
若您的订阅节点中带有 `Auto` 或 `Url-Test` 组，小火箭会在后台自动并发检测节点延迟，并 **自动将流量切换至当前响应速度最快、丢包率最低的节点** 上，无需手动反复选择。

## ❓ 第七章：常见故障排查手册与 FAQ 问答集

### Q1: 首次开启开关提示“Shadowrocket 想要添加 VPN 配置”，点击允许后无法成功？
**答：** 这是由于 iOS 系统权限未成功赋予所致。请确保在弹出的系统对话框中点击了 **“允许”**，并在跳转到的苹果系统界面中输入正确的 **iPhone 锁屏数字密码** 或完成 **Face ID** 验证。若仍失败，请重启 iPhone 后重试。

### Q2: 开启小火箭后出现全网断网，节点测速全部显示 `Timeout` 或 `Connection Refused`？
**答：** 
1. **检查系统时间**：前往 iPhone「设置 → 通用 → 日期与时间」，确保勾选了 **“自动设置”**。如果手机时间与标准时间相差超过 30 秒，TLS 协议握手会被强制拒绝。
2. **节点过期或 IP 变更**：首页向下拉动更新订阅，获取最新的节点服务器地址。
3. **切换网络**：在 Wi-Fi 与蜂窝数据之间切换测试，排查是否由于当前 Wi-Fi 防火墙封禁了代理端口。

### Q3: 开启小火箭后，微信、抖音、淘宝等国内 App 无法加载图片或视频？
**答：** 请确认首页底部的全局路由是否误设为了 `Proxy`（全局代理）模式。必须将其设为 **`Config` (配置)** 模式，国内应用流量即可恢复直连毫秒级加载。

### Q4: 订阅链接导入提示 `Download Failed` 或 `Invalid URL`？
**答：** 确认复制的订阅 URL 格式完整且以 `https://` 开头。若使用 Safari 可以打开该链接，请检查订阅链接中是否包含了特殊空格或中文字符。

### Q5: 访问外网时网页提示“您的连接不是私密连接”或证书无效？
**答：** 这通常是因为您开启了 HTTPS 解密但未在系统中彻底信任 CA 证书。请前往「设置 → 通用 → 关于本机 → 证书信任设置」，确保针对 Shadowrocket CA 根证书开启了完全信任。

### Q6: 游戏联机提示丢包严重、延迟高或者无法连接语音？
**答：** 游戏联机依赖强 UDP 传输。请优先选用支持 **Hysteria2 (Hy2)** 协议的专线节点，并在小火箭中开启 UDP 转发支持。
