## 🚀 什么是 Shadowrocket？深入了解“小火箭”

## 🔥 第一章：小火箭核心功能体系全景剖析

### 1.1 🧠 智能规则分流
根据不同网站与 IP 自动切换连接策略：国内直连毫秒级响应，代理流量精准转发。支持域名后缀（Domain-Suffix）、IP-CIDR、GEOIP 地理位置等多维度规则匹配，减少资源占用并提升整体访问效率，让每一条流量都走最优路径。

### 1.2 🔌 多协议全兼容
全面支持 Shadowsocks (SS)、V2Ray (VMess / VLESS)、Trojan、Hysteria2 (Hy2)、TUIC v5、Snell、Socks5 及 HTTP/HTTPS 等主流代理协议，并持续适配新协议。配合订阅管理模式，一键导入即用，适配复杂的网络环境。

### 1.3 📊 节点测速系统
内置专业级延迟检测引擎，自动检测各节点的 ICMP 延迟、TCP 握手时间与 HTTP 实际响应状态。支持批量测速与定时自动测速，以可视化数据帮助用户快速筛选优质线路，告别盲目切换。

### 1.4 🛡️ 数据隐私保护
支持本地规则控制与精细化流量策略管理，所有配置数据仅存储于本地设备。端到端加密传输，不经过任何第三方服务器，从架构层面优化连接安全性，守护您的数字隐私。

### 1.5 🔄 场景自动无感切换
按 Wi-Fi 网络 SSID 名称、蜂窝数据、特定网络接口等条件自动切换代理策略。在家直连、外出加密、办公分流——全程自动化，无需手动操作，让网络管理真正实现无感运行。

### 1.6 📱 iOS 原生生态融合
严格遵循 iOS 设计规范，界面简洁直观。支持 iOS 桌面 Widget 小组件、Siri 快捷指令（Shortcuts）、Apple Watch 联动。极低的后台资源占用，长时间运行不发热不耗电。

## 📲 第二章：iOS 客户端获取、安装与安全授权

由于 App Store 区域政策限制，Shadowrocket 需要在美区、港区或日区等境外 App Store 账号下进行获取。

### 2.1 步骤一：获取并登录外区 Apple ID
1. 打开 iPhone 的 **App Store** 应用。
2. 点击右上角个人头像，滑动到最底部，点击 **“退出登录”**（注意：仅在 App Store 退出，**无需退出 iCloud 账号**，确保手机数据安全）。
3. 填入准备好的外区 Apple ID 与密码并登录。
4. 在搜索框输入 `Shadowrocket`，认准开发者信息与官方小火箭图标完成下载。

### 2.2 步骤二：首次启动与 VPN 配置文件授权
1. 安装完成后打开小火箭应用。
2. 首次点击顶部最上方的 **“未连接”** 开关时，iOS 系统会弹出安全授权对话框：
   ```
   “Shadowrocket”想要添加 VPN 配置
   通过代理过滤的网络活动可能会被监听或拦截。
   ```
3. 点击 **“允许 (Allow)”**。
4. 屏幕将自动跳转至 iOS 系统验证界面，输入您的 **iPhone 数字锁屏密码**，或通过 **Face ID / Touch ID** 进行安全确认。

## ⚡ 第三章：节点订阅导入与自动化管理

订阅链接（Subscription URL）是代理服务商提供的一个专属配置接口，导入后可一次性拉取数十个甚至上百个节点。

```
准备订阅 URL  ──>  小火箭右上角 [+]  ──>  类型选择 [Subscribe]  ──>  粘贴链接并保存  ──>  开启 [配置] 模式
```

### 3.1 手动一键粘贴导入
1. 复制代理服务商（机场）后台提供的 Shadowrocket / Clash 专属订阅 URL。
2. 打开 Shadowrocket，点击首页右上角的 **`+` 加号**。
3. 在弹出的页面中，点击 **类型 (Type)** 栏，将其切换为 **`Subscribe` (订阅)**。
4. 在 **URL** 粘贴框中粘贴刚刚复制的链接。
5. 在 **备注 (Remark)** 栏输入便于识别的机场名称（如“专线机场”）。
6. 点击右上角的 **“保存 (Save)”** 按钮。小火箭将立即发起网络请求拉取全部节点信息。

### 3.2 扫码与剪贴板自动识别
- **扫码导入**：点击小火箭首页左上角的 **扫码图标**，对准机场后台提供的订阅二维码或节点二维码扫描即可瞬间完成添加。
- **剪贴板识别**：复制订阅链接后打开小火箭，应用会自动弹窗识别剪贴板内容，询问是否导入。

### 3.3 设置自动更新与后台静默刷新
进入小火箭 **「设置」 → 「订阅」** 菜单：
- 开启 **“打开时更新” (Update on Open)**：每次打开小火箭时自动刷新节点列表。
- 开启 **“自动更新” (Auto Update)**：设置每 24 小时在后台自动更新一次订阅，确保节点信息时刻最新。

## ⚙️ 第四章：四种路由模式与规则分流高级配置

在 Shadowrocket 首页底部，找到 **全局路由 (Global Routing)** 选项，点击可切换以下四种核心模式：

| 路由模式 | 英文名称 | 推荐指数 | 工作逻辑与使用场景 |
| :--- | :--- | :---: | :--- |
| **配置模式 (推荐)** | `Config` | 🌟🌟🌟🌟🌟 | **最推荐使用**。根据分流规则自动识别：国内流量直连、境外流量走代理，兼顾速度与流量 |
| **代理模式** | `Proxy` | 🌟🌟 | **全量代理**。所有网络流量强制通过选定的代理节点转发，适合特殊调试 |
| **直连模式** | `Direct` | 🌟🌟 | **完全直连**。所有网络流量直接连接，相当于暂时关停代理功能 |
| **场景模式** | `Scene` | 🌟🌟🌟🌟 | **智能自动**。根据 Wi-Fi 名称或蜂窝移动网络自动应用预设的场景规则 |

### 4.1 引入第三方社区成熟规则集
除了小火箭内置的默认规则外，您还可以导入社区开源维护的高精细度规则集（如 **Loyalsoldier 规则** 或 **ACL4SSR 规则**）：
1. 在小火箭底部点击 **「配置」** 标签。
2. 点击右上角的 **`+`** 号。
3. 粘贴规则集远程地址（如 `https://raw.githubusercontent.com/Loyalsoldier/clash-rules/release/shadowrocket.conf`）。
4. 下载后点击该配置文件，选择 **“使用配置”** 即可完成切换。

## 📊 第五章：节点测速系统与线路智能选优

### 5.1 测速机制详解 (ICMP vs TCP vs HTTP)
点击首页节点列表上方的 **“连通性测试”**，小火箭会同时对所有节点发起响应测试：
- **TCP 测速**：测试手机与代理节点之间的 TCP 三次握手耗时，数值最能反映节点本身的响应速度。
- **HTTP 测速**：测试通过该节点实际访问 Google 或百度等真实网站的端到端耗时，数值最贴近真实上网体验。

### 5.2 策略组自动选优 (Auto Test)
如果您使用的订阅中包含 `Auto` 或 `Url-Test` 策略组，小火箭会在后台定期对组内节点进行测速，并 **自动把流量分配到当前延迟最低、连通率最高的节点上**，无需手动频繁切换。

## 🛠️ 第八章：常见故障与错误代码排查手册

### 8.1 现象 1：开启连接后所有节点显示 `Timeout` 或 `Connect Failed`？
- **检查步骤**：
  1. 确认手机系统时间是否准确。前往「设置 → 通用 → 日期与时间」，开启 **“自动设置”**。时间偏差过大将直接导致 TLS 安全握手失败。
  2. 尝试向下拉动首页刷新订阅列表，确认机场节点 IP 未被服务商更换。
  3. 切换 Wi-Fi 与移动 4G/5G 网络再次测试。

### 8.2 现象 2：开启小火箭后国内 App（微信/抖音/淘宝）加载卡顿？
- **解决办法**：请检查首页底部的 **“全局路由”** 是否被误设置成了 `Proxy`（代理）。将其切换回 **`Config`（配置）** 模式，国内流量即可瞬间恢复直连。

### 8.3 现象 3：订阅导入提示 `Download Failed`？
- **解决办法**：确认复制的链接无误且包含 `https://` 开头。若订阅链接在 Safari 中打不开，可尝试在连接 Wi-Fi 的情况下再次点击更新。
