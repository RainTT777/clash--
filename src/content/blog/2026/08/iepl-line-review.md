## 💡 机场选购核心避坑与对比指标

在选择适合自己的机场服务商时，建议从以下 4 个关键维度进行综合考量：

1. **线路架构（BGP 中转 vs IEPL 专线）**：
   - **直连线路**：容易受公网拥堵影响，晚高峰速度波动较大。
   - **IEPL 内网专线**：不经过公网 GFW 审查，数据走局域网内网点对点传输，延迟极低且全天候无拥堵。

2. **流媒体与 AI 解锁能力**：
   - 是否支持 Netflix / Disney+ / HBO 港台及美区原生 IP 解锁。
   - 是否支持 OpenAI (ChatGPT)、Claude 3.5 及 Google Gemini 的原生节点访问，避免频繁出现 IP 被封禁风险。

3. **客户端兼容性与通用订阅格式**：
   - 优质机场均支持 **Clash (YAML)**、**Shadowrocket (SS/V2Ray/Trojan)**、**Sing-Box (JSON)** 以及 **Surge** 等通用订阅格式。

4. **SLA 稳定性保障**：
   - 观察服务商是否具备多入口冗余与备用节点，避免单入口故障导致全网断连。

3. 粘贴订阅链接并点击保存，连通性测试后勾选最快节点即可开启智能代理。

### 2. Windows / macOS Clash Verge 配置步骤
1. 下载安装最新的 Clash Verge Rev 客户端。
2. 登录机场后台，点击 **“复制 Clash 订阅地址”**。
3. 打开 Clash Verge，进入 **订阅 (Profiles)** 页面，粘贴 URL 并点击 **Import**。
4. 切换至 **代理 (Proxies)** 页面，选择 `规则模式 (Rule)`，选择线路后开启全局系统代理即可！
