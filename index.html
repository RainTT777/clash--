三步极速上手 Clash

无需繁琐配置，跟随以下三个核心步骤，即可从零开始快速上手 Clash，享受极速流畅的网络代理体验：

  1. 下载并安装对应平台的 Clash 客户端：根据您使用的操作系统（Windows、macOS、Android、iOS 或 Linux），前往获取对应的 Clash 图形化客户端。推荐 Windows / macOS 用户选择 Clash Verge Rev，Android 用户选择 Clash Meta for Android，iOS 用户选择 Shadowrocket (小火箭)。
  2. 在「配置」页面粘贴您的代理订阅链接：打开已安装的 Clash 客户端，找到「配置」（Profiles）或「订阅」菜单，将您向代理服务商购买后获得的订阅链接粘贴进去，点击下载/更新，客户端将自动拉取并解析所有节点信息。
  3. 切换至「规则」模式并开启代理：进入「代理」（Proxies）页面，在顶部模式选择处选择 「规则」（Rule）模式——此模式会根据预设规则自动判断哪些流量走代理、哪些直连。最后开启系统代理或 TUN 开关即可。

第一章：Clash 架构全景解析与核心优势

Clash 底层完全由 Go 语言编写，充分利用了 Go 的 goroutine 轻量级并发模型，在大流量与高并发连接场景下依然能够保持极低的 CPU 与内存开销。

1.1 Clash 的核心设计理念

传统 VPN 工具通常采用全盘重定向（Full-Tunneling）模式，无论访问国内百度还是国外 GitHub，所有网络流量均强制通过单一代理网关转收。这种模式存在明显的弊端：访问国内网站延迟陡增、视频加载卡顿、带宽资源浪费严重。

Clash 则是典型的 规则驱动型代理引擎（Rule-Based Proxy Engine）。它在操作系统与网络出口之间建立了一个精细化的分流路由层。当客户端发起网络请求时，Clash 能够在毫秒级时间内检测目标域名、目标 IP 地址、连接端口乃至请求发起进程，严格对照用户设定的规则库，做出如下决策：

  • DIRECT (直连)：流量不经过代理，直接由本地网络接口连接目标服务器（适用于微信、淘宝、百度、Bilibili 等国内服务）。
  • PROXY (代理)：流量通过指定的加密代理节点转发（适用于 Google、YouTube、GitHub、OpenAI 等境外服务）。
  • REJECT (拦截)：直接丢弃请求，起到广告拦截与恶意追踪屏蔽的作用。

1.2 Mihomo (Clash Meta) 内核演进

原版 Clash 核心在社区停止维护后，Mihomo (原名 Clash Meta) 作为功能最强劲的社区分流继承者脱颖而出。Mihomo 不仅继承了 Clash 原生的全部能力，还扩充了以下前沿特性：

  • 支持 Hysteria2 (Hy2) 与 TUIC v5 等基于 QUIC 协议的下一代抗丢包代理。
  • 支持 VLESS + Reality 极隐蔽传输协议。
  • 引入 Rule-Set (规则集) 远程异步加载机制，极大简化了配置文件的体积。
  • 增强了 Geodata (geoip.dat / geosite.dat) 解析性能，使地理位置识别更加精准。

1.3 全协议兼容支持清单

现代 Clash 客户端（配搭 Mihomo 内核）可轻松支持市场上所有主流与前沿协议：Shadowsocks (SS / SS-2022)、VMess / VLESS、Trojan、Hysteria2 (Hy2) 及 TUIC v5。

第二章：全平台客户端安装与全流程上手指南

2.1 Windows 平台安装指南 (以 Clash Verge Rev 为例)

Clash Verge Rev 是目前 Windows 平台最受推荐的开源 GUI 客户端，内置 Mihomo 内核，界面现代且易于维护。

  1. 获取安装包：下载最新的 Clash.Verge_x64-setup.exe 文件。
  2. 处理 SmartScreen 安全警报：若 Windows 弹出“Windows 已保护你的电脑”提示，点击 “更多信息” → “仍要运行” 即可。
  3. 完成安装向导：按提示完成安装，勾选“创建桌面快捷方式”。
  4. 开启系统代理与开机启动：打开 Clash Verge Rev，在左侧菜单进入「设置」，开启 “开机自启 (Auto Launch)” 与 “系统代理 (System Proxy)” 开关。

2.2 macOS 平台安装指南

  1. 确认架构类型：点击屏幕左上角苹果图标  → “关于本机”。Apple M 系列芯片选择 arm64.dmg，Intel 芯片选择 x64.dmg。
  2. 拖拽安装：双击 `.dmg` 文件，将 Clash 拖入 Applications 文件夹。
  3. 解除开发者隔离提示：若提示无法打开，在终端执行： 
    sudo xattr -rd com.apple.quarantine /Applications/Clash\ Verge.app

2.3 Android 平台安装指南

下载 Clash Meta for Android (CMFA) 的 arm64-v8a.apk，允许未知来源安装。首次连接时在 Android 系统弹出的“建立 VPN 连接”窗口中点击 “确定” 授权。

2.4 iOS 平台安装指南

推荐使用支持 Clash 格式的 Shadowrocket (小火箭)。使用美区 Apple ID 登录 App Store 下载，并在应用内粘贴 Clash `.yaml` 订阅 URL 完成一键导入。

2.5 Linux 桌面与服务器部署

第三章：订阅链接机制与 YAML 格式深度剖析

订阅链接（Subscription URL）是代理服务商提供的专属 HTTP 链接。客户端访问该链接时，服务器会返回包含所有节点服务器地址、端口、密钥及路由规则的 YAML 配置文件。

建议将订阅更新间隔设定为 1440 分钟（24小时），开启 url-test 自动测速策略组，向测试点发送检测请求，自动将流量切换到延迟最低的节点。

第四章：三大代理模式与分流路由引擎详解

代理模式 英文标识 核心逻辑 最佳适用场景
规则模式 (推荐) Rule 智能分流。按规则库自动识别流量，国内直连、境外走代理 99% 日常使用场景，兼顾速度与流量消耗
全局模式 Global 全量代理。所有流量一律通过用户选定的单一代理节点转发 访问特定偏门网站或调试网络
直连模式 Direct 完全直连。绕过所有代理节点，所有流量直接连出 临时关闭代理功能

4.1 核心规则匹配类型示例

rules:
  - DOMAIN,google.com,代理节点          # 精确域名匹配
  - DOMAIN-SUFFIX,youtube.com,代理节点   # 域名后缀匹配
  - DOMAIN-KEYWORD,telegram,代理节点    # 域名关键词匹配
  - IP-CIDR,192.168.0.0/16,DIRECT       # IP-CIDR 段匹配
  - GEOIP,CN,DIRECT                     # GEOIP 中国地理库匹配
  - MATCH,代理节点                       # 默认兜底规则

第五章：DNS 防污染与 DoH/DoT 加密配置

传统 DNS 明文 UDP 查询易遭污染劫持。Clash 强烈推荐使用 Fake-IP 模式：在收到 DNS 查询时立即返回虚拟 IP 网段（如 198.18.0.1/16），无需等待本地 DNS 解析即可建立连接，完全免疫本地 DNS 污染。

dns:
  enable: true
  listen: 0.0.0.0:53
  enhanced-mode: fake-ip
  fake-ip-range: 198.18.0.1/16
  nameserver:
    - https://doh.pub/dns-query     # 腾讯 DNSPod DoH
    - https://dns.alidns.com/dns-query # 阿里 AliDNS DoH
    - https://1.1.1.1/dns-query        # Cloudflare Secure DoH

第六章：Web Dashboard API 控制器极客部署

在配置文件中声明 API 控制器监听与密钥：

external-controller: 127.0.0.1:9090
secret: "MySecretToken2026"

打开控制面板（如 https://metacubexd.pages.dev 或 https://yacd.haishan.me），填入 API 地址与密钥，即可在浏览器中可视化进行延迟测速与流量监控。

第七章：TUN 模式接管全量流量与游戏低延迟优化

针对不遵循系统代理的命令行工具、UDP 联机游戏（Steam、Epic、Valorant、Apex），TUN 模式会在内核中创建虚拟网卡接管系统全量数据包：

tun:
  enable: true
  stack: system
  dns-hijack:
    - "any:53"
  auto-route: true
  auto-detect-interface: true

结合 Hysteria2 (Hy2) 协议与 url-test 自动测速，可以在丢包高峰期大幅提升网络稳定度。

第八章：常见故障排查手册与 FAQ 问答集

Q1: 开启 Clash 代理后电脑全网断网，无法打开任何网页？

答： 1. 检查选中的节点是否失效（在代理面板点击闪电图标测速，确认选中的节点延迟正常而非 Timeout）。
2. 检查系统时间是否与标准北京时间精准同步（误差超过 30 秒会导致 TLS 证书校验失败）。
3. 检查是否有端口冲突，可以在客户端设置中将混合端口更改为 7897 或 7890。

Q2: 订阅更新失败，提示 Download Failed 或 YAML Parse Error？

答： 出现此提示通常因为服务商返回的是 Base64 字符串而非标准 YAML 配置文件。请联系服务商复制专用的 Clash 订阅 URL，或使用订阅转换工具转换为 Clash 兼容格式。

Q3: 访问微信、百度或 Bilibili 等国内网站极其缓慢或加载失败？

答： 请确认代理模式是否处于 「规则 (Rule)」模式，而非「全局 (Global)」模式。若在规则模式下仍有部分国内网站走了代理，可在配置文件的 rules 中追加自定义直连规则（如 DOMAIN-SUFFIX,baidu.com,DIRECT）。

Q4: 游戏联机提示 NAT 类型受限或 UDP 节点连接超时？

答： 大部分游戏联机（如 Epic/Steam/Valorant）依赖 UDP 协议。请务必开启 TUN 模式 并确保选择的节点开启了 UDP 转发支持，优先选用 Hysteria2 (Hy2) 协议节点。

Q5: 浏览器可以翻墙，但 PowerShell / CMD / Terminal 命令行无法拉取 GitHub？

答： 系统代理（System Proxy）默认不接管终端命令行。可通过启用 TUN 模式 强制接管全局系统流量，或在命令行中临时手动配置环境变量：$env:HTTP_PROXY="http://127.0.0.1:7897"。

Q6: Windows 微软商店 (Microsoft Store) 及 UWP 应用开启代理后无法联网？

答： Windows 对 UWP 规范应用默认开启了回环隔离保护。请在 Clash Verge 客户端的「工具」菜单中打开 “UWP Loopback 豁免工具”，勾选需要代理的微软应用并保存设置即可。

Q7: 如何保障个人机场订阅链接与节点信息的安全性？

答： 订阅链接相当于您的个人账号访问凭证，切勿将链接公开发布在论坛、GitHub 或代码仓库中。若不慎泄漏，请立即登录机场官网后台点击“重置订阅链接”生成全新 URL。

总结： 熟练掌握 Clash 的规则分流、Mihomo 内核与 TUN 模式，能让您的网络连接兼顾极致速度与安全隐私。立即体验高速专线节点，解锁顺畅无阻的网络世界！
